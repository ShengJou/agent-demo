# Agent Executor 工具调用测试

## 问题诊断

如果您遇到 stream 没有输出调用工具结构的问题，请按以下步骤排查：

### 1. 运行调试测试

```bash
npm run test-tools
```

这将运行一个简单的测试脚本，显示流式输出的完整结构。

### 2. 运行主程序

```bash
npm start
```

然后尝试输入一个需要搜索的问题，比如：

- "旧金山的天气怎么样？"
- "搜索一下北京的天气"

### 3. 检查调试输出

程序现在会显示详细的调试信息：

- `[调试] 块属性` - 显示每个流式块包含的属性
- `[调试] 工具调用数量` - 显示工具调用的数量
- `[调试] 完整工具调用结构` - 显示完整的工具调用数据结构

### 4. 可能的原因

如果仍然没有工具调用，可能的原因包括：

1. **模型没有选择调用工具**

   - 确保您的问题明确需要搜索
   - 尝试更直接的问题："搜索天气信息"

2. **模型配置问题**

   - 检查 `llm.ts` 中的模型配置
   - 确保使用的是支持工具调用的模型

3. **工具定义问题**

   - 检查 `src/tools.ts` 中的工具定义
   - 确保工具的描述清晰明了

4. **API 配置问题**
   - 检查 `.env` 文件中的 API 密钥
   - 确保 API 密钥有效

### 5. 环境变量

确保您的 `.env` 文件包含：

```
DEEPSEEK_API_KEY=your_api_key_here
```

## 预期行为

正常情况下，当您输入需要搜索的问题时，应该看到：

1. 流式文本输出
2. 工具调用检测信息
3. 工具执行结果
4. 基于工具结果的最终回答

如果您看到了调试信息但没有工具调用，说明模型选择了不使用工具，尝试更明确的提示。
